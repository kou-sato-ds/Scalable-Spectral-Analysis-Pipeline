Context（背景）: スペクトル分析にはSNVや微分などの複雑な物理計算が必要だが、Spark標準関数だけでは実装が困難、かつコードの可読性が著しく低下する。

Decision（決定）: 物理ロジックの柔軟性と分散処理を両立するため、Pandas UDFを採用する。

Consequences（結果）:

(+) NumPy/SciPy の強力な科学計算ライブラリを分散環境でそのまま利用可能。

(+) Apache Arrow 経由のベクトル化転送により、通常の Python UDF よりも劇的に高速化。

(-) JVM/Python 間のオーバーヘッドはゼロではないため、可能な限り一括処理（Batch処理）を行う設計とする。
